# Brainstorming Session Results

**Facilitator:** Developer
**Date:** 2026-02-06

## Session Overview

**Topic:** Improving web consumption experience for Stage OTT platform trial users acquired via Meta/Google ads

**Goals:** Design pull-based experiments to increase content consumption start on mobile web browsers (Meta/Google in-app browsers) while keeping user experience at the core — using a pull-based strategy rather than push

### Session Setup

**Business Context:**
- Stage is a regional OTT platform (Haryanvi, Rajasthani, Bhojpuri, Gujarati content)
- Pricing: 7-day trial at ₹1, then ₹199/month
- User acquisition via Meta and Google ads
- New brand ambassador: Randeep Hooda driving traffic
- Web ad campaigns are scaling — traffic and trial conversions are good
- Problem: Trial users are NOT installing the app, and web consumption start is very low
- Current flow: Pre-trial experience on web → trial → attempt app download push
- Users are consuming inside mobile browsers (likely Meta or Google in-app browsers)

**Key Constraints:**
- Pull-based strategy (not push/forced)
- User experience must remain at the core
- Mobile web browser environment (in-app browsers have limitations)
- Regional language audiences with specific content preferences
